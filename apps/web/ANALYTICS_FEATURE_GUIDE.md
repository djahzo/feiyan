# 数据分析与智能推荐系统实现文档

## 功能概述

本次更新为「飞燕」管理后台添加了完整的**数据分析**和**智能排期推荐**功能，解决了以下问题：

1. ✅ 缺乏扫号数据导出能力 → 支持 CSV/JSON 格式导出
2. ✅ 无法分析上号托管频率 → 提供可视化统计展示
3. ✅ 排期缺乏公平性 → 基于权重模型的智能推荐系统

---

## 新增功能模块

### 1️⃣ 数据分析页面 (`/admin/analytics`)

#### 功能特性
- **总览统计**：展示托管天数、总次数、日均次数、参与舰长数
- **类型分布**：扫号 vs 组排的比例分析
- **舰长频率**：每个舰长的托管次数、最近托管日期、平均间隔
- **日期统计**：按日期查看托管安排和舰长列表
- **数据导出**：支持 CSV 格式导出舰长频率、日期统计、全部记录

#### 使用方式
1. 导航到「数据与策略」→「数据分析」
2. 选择起始和结束日期（默认最近90天）
3. 切换「总览」「舰长频率」「日期统计」标签查看不同维度
4. 点击「导出CSV」按钮下载数据

---

### 2️⃣ 排期权重配置页面 (`/admin/scheduling-config`)

#### 权重模型设计

```
权重分数 = (距上次托管天数 × 时间因子权重)
         + (舰长等级分数 × 等级因子权重)
         - (历史托管次数 × 频率惩罚权重)

新舰长：直接获得配置的新舰长默认分数（默认 99999，确保最高优先级）
```

#### 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 时间因子权重 | 1.0 | 距离上次托管的天数越多，权重分数越高 |
| 等级因子权重 | 0.3 | 总督=3分、提督=2分、舰长=1分，乘以此系数 |
| 频率惩罚权重 | 0.2 | 历史托管次数越多，扣减的分数越多 |
| 新舰长默认分数 | 99999 | 从未托管过的新舰长直接获得此分数 |
| 启用智能推荐 | 开启 | 是否启用推荐功能 |

#### 使用方式
1. 导航到「数据与策略」→「排期权重配置」
2. 调整各项权重参数
3. 点击「预览推荐结果」查看基于当前配置的 Top 20 舰长排序
4. 点击「保存配置」使配置生效

## 使用场景示例

### 场景 1：查看舰长托管频率
1. 打开「数据分析」页面
2. 切换到「舰长频率」标签
3. 查看每个舰长的托管次数和距今天数
4. 点击「导出CSV」保存为电子表格

### 场景 2：导出本月所有托管记录
1. 打开「数据分析」页面
2. 设置起始日期为本月1日，结束日期为今天
3. 切换到「日期统计」标签
4. 点击「导出所有记录」下载 CSV

### 场景 3：调整推荐算法
1. 打开「排期权重配置」页面
2. 如果希望更重视「轮流雨露均沾」，增大「时间因子权重」到 1.5
3. 如果希望减少对频繁上号者的惩罚，降低「频率惩罚权重」到 0.1
4. 点击「预览推荐结果」查看效果
5. 满意后点击「保存配置」

### 场景 4：获取下次应该安排的舰长
1. 调用 API: `GET /api/admin/recommendations?top=5`
2. 返回分数最高的前 5 名舰长
3. 优先安排这些舰长的托管排期

## 权重模型说明

### 计算示例

假设当前配置为默认值：
- 时间因子权重 = 1.0
- 等级因子权重 = 0.3
- 频率惩罚权重 = 0.2

#### 示例 1：老舰长
- 王老板（总督）
- 上次托管：42天前
- 历史次数：10次

```
时间分 = 42 × 1.0 = 42.0
等级分 = 3 × 0.3 = 0.9
频率惩罚 = 10 × 0.2 = 2.0
最终分数 = 42.0 + 0.9 - 2.0 = 40.9
```

#### 示例 2：新舰长
- 李姐（舰长）
- 从未托管过

```
最终分数 = 99999（新舰长默认分数）
```

#### 示例 3：最近刚托管过的舰长
- 张总（提督）
- 上次托管：3天前
- 历史次数：15次

```
时间分 = 3 × 1.0 = 3.0
等级分 = 2 × 0.3 = 0.6
频率惩罚 = 15 × 0.2 = 3.0
最终分数 = 3.0 + 0.6 - 3.0 = 0.6
```

**推荐顺序**：李姐（99999） > 王老板（40.9） > 张总（0.6）

## 故障排查

### 问题 1：推荐结果为空
**原因**：智能推荐功能被禁用  
**解决**：前往「排期权重配置」，勾选「启用智能推荐」

### 问题 2：导出CSV后中文乱码
**原因**：Excel默认使用GBK编码  
**解决**：
1. 用记事本打开CSV文件
2. 另存为，选择编码为「UTF-8 with BOM」
3. 再用Excel打开

### 问题 3：推荐分数不符合预期
**原因**：权重配置不合理  
**解决**：
1. 使用「预览推荐结果」功能查看分数明细
2. 调整各项权重系数
3. 多次预览直到满意
